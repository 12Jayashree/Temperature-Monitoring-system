# FPGA-Based Real-Time Temperature Monitoring and Predictive Thermal Management System Using Intelligent Sensor Interfaces

## 📌 Project Overview

This project presents an FPGA-based real-time temperature monitoring and predictive thermal management system using intelligent sensor interfaces.

The system is designed to continuously monitor temperature data and provide thermal management based on the detected temperature conditions.

## 🎯 Objectives

- Real-time temperature monitoring
- Interface temperature sensors with FPGA
- Process and analyze temperature data
- Detect abnormal/high-temperature conditions
- Provide predictive thermal management
- Implement the system using VLSI/FPGA design techniques

## 🛠️ Technologies Used

- VLSI Design
- FPGA
- Verilog HDL
- AMD/Xilinx Vivado
- Digital System Design
- Temperature Sensor Interface

## 📂 Project Files

The `Temperature_monitor.zip` file contains the Vivado project files and related design files.

## ⚙️ Project Implementation

The project is developed and simulated using AMD/Xilinx Vivado.

The FPGA processes the temperature sensor data and generates the required thermal management response according to the temperature conditions.

## 🔬 Applications

- Smart thermal monitoring
- FPGA-based embedded systems
- Industrial temperature monitoring
- Electronic device thermal protection
- Intelligent thermal management systems

## 👩‍💻 Project Type

**VLSI / FPGA Based Project**
